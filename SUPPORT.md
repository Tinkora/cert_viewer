# Support

This repository applies [Tinkora's organization-wide community policies](https://github.com/Tinkora/.github) with the Cert Viewer-specific support routes below.

## Usage Questions

Read the [README](README.md), [schema guide](docs/schema/README.md), and [self-hosting guide](docs/SELF_HOSTING.md) first. Ask remaining how-to and interpretation questions in [GitHub Discussions](https://github.com/tinkora/cert_viewer/discussions). Do not include sensitive certificate content.

## Reproducible Bugs

Use the [bug report form](https://github.com/tinkora/cert_viewer/issues/new?template=bug.yml) when current behavior differs from documented behavior. Include the version or commit, browser and operating system, exact steps, expected and actual outcomes, and a minimal public or synthetic certificate when one is necessary.

## Evidence-Backed Features

Use the [feature request form](https://github.com/tinkora/cert_viewer/issues/new?template=feature.yml) for a demonstrated user workflow that fits local-only, inspection-only behavior. Explain who has the problem, current workarounds, evidence of recurring need, alternatives, and the smallest useful outcome. Ideas without evidence belong in Discussions until the need is clearer.

## Security

Report suspected vulnerabilities only through [GitHub Private Vulnerability Reporting](https://github.com/tinkora/cert_viewer/security/advisories/new). Do not disclose them in Issues, Discussions, or pull requests. The [security policy](SECURITY.md) defines scope and response expectations.

## Conduct

Report Code of Conduct concerns privately using the maintainer contact discovery path in the [Code of Conduct](CODE_OF_CONDUCT.md). Do not litigate conduct reports in public project channels.

## What Maintainers Can Provide

Maintainers can clarify documented behavior, triage reproducible defects, and evaluate evidence-backed proposals. They cannot provide certificate issuance, PKI operations, incident response, legal advice, or a decision that a certificate is trustworthy or suitable for a hostname.
